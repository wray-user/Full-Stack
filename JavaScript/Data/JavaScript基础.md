## 1.1 JavaScript 介绍

### 1.1.1 JavaScript 是什么

JavaScript 是一种运行在客户端（浏览器）的编程语言，实现人机交互效果。有以下作用：

- 网页特效（监听用户的一些行为让网页做出对应的反馈）
- 表单验证（针对表单数据的合法性进行判断）
- 数据交互（获取后台的数据，渲染到前端）
- 服务端编程（node.js）

JavaScript 由两部分组成：

- ECMAScript（JS基础语法）：规定了js基础语法。
- Web APIs
  - DOM：页面文档对象模型（如页面对元素进行移动、大小、添加删除等操作）
  - BOM：浏览器对象模型（如页面弹窗、检测窗口宽度、存储数据到浏览器等）

### 1.1.2 JavaScript 书写位置

1. 行内：内联 js，代码写在标签内部。

   ```html
   <body>
       <button onclick="alert('你好')">
           点击
       </button>
   </body>
        
   ```

2. 内部：直接写在 html文件里，用 script 标签包住。

   - 规范：script 标签写在 `</body>`上面

   - 拓展：`alert('你好')` 页面弹出警告对话框

     ```html
     <body>
         <button class="pink">按钮1</button>
         <script>
         	// 内容
         </script>
     </body>
     ```

     

     >我们将`<script>` 放在HTML文档的底部附近是因为浏览器会按照代码在文件中的顺序加载HTML。

3. 外部：代码可以写在 .js 文件里。

   - 语法：通过 script 标签引入到 html 页面中。

     ```html
     <body>
         <script src="my.js"></script>
     </body>
     ```



### 1.1.3 JavaScript 注释和结束符

- 注释：
  1. 单行注释： // ； ctrl + /
  2. 多行注释： /* */ ； shift + alt + a
- 结束符：; . 实际开发中可写可不写，浏览器自动推断语句结束位置。



### 1.1.4 输入和输出语法

输入语法：

-  语法：`prompt('请输入您的姓名：')`。显示一个对话框，对话框中包含一条文字信息，用来提示用户输入文字。





输出语法：

- 语法1：`document.write('要输出的内容')`。向 body 内输出内容。如果输出的内容写的是标签，也会被解析伪网页元素。
- 语法2：`alert('要输出的内容')`。页面弹出警告对话框。
- 语法3：`console.log('控制台打印')`。控制台输出语法，程序员调试使用。

## 1.2 变量

### 1.2.1 变量是什么

变量是计算机中用来存储数据的“容器”。



### 1.2.2 变量的基本使用

1. 声明变量

   - 语法：`let 变量名`. （ `var 变量名`  是前任）

2. 变量赋值

   定义一个变量之后，需要赋值 “=”。 初始化。

3. 更新变量
   重新赋值即可。

4. 声明多个变量
   变量赋值后，多个变量中间用逗号隔开。`let age = 18, uname = 'pink'`



### 1.2.3 变量的本质

是程序在内存中申请的一块用来存放数据的小空间。





### 1.2.4 变量命名规则和规范

1. 规则：
   - 不能使用关键字
   - 只能使用下划线、字母、数字、$组成，且数字不能开头。
   - 字母严格区分大小写。
2. 规范：
   - 起名有意义
   - 小驼峰命名法：第一个单词首字母小写，后面每个单词字母大写。useName



### 1.2.5  数组的基本使用

数组（Array）：一种将一组数据存储在单个变量名下的方式。

1. 声明语法：`let 数组名 = [数据1, 数据2, ..., 数据n]`
2. 取值方法：`数组名[下标]`





## 1.3 常量

使用 const 声明的变量称为“常量”。`const G = 9.8`。 

- 常量不允许重新赋值，声明的时候必须赋值（初始化）



## 1.4 数据类型

### 1.4.1  数据类型分类

1. 基本数据类型
   - number 数字型
   
     - 数学中学习到的数据，整数、小数、正数、负数。
   
       >Js 是若数据类型，变量到底属于那种类型，只有赋值之后，我们才能确认。
   
     - 算术运算符：+、-、*、/、%。
   
     
   
   - string 字符串型
   
     - 通过单引号（' '）、双引号（" "）、或反引号（\` \`) 包裹的数据都叫字符串。
     - 字符串的拼接： + 运算符，可实现字符串拼接。
     - 模板字符串：拼接字符串和变量。
       - \`\`(反引号)。内容拼接变量时，用` &{}`包住变量。
   
   - boolean 布尔型
   
     - true 和 false 
   
   - undefined 未定义型
   
     - 只声明变量，不赋值的情况下，变量的默认值为 undefined，一般很少直接为某个变量赋值为 undefined.
   
   - null 空类型
   
     - 赋值了，但是内容为空。
   
2. 引用数据类型
   - object 对象



### 1.4.2 数据类型检测

1. 控制台输出语句: `console.log(变量)`

2. 通过 typeof 关键字检测数据类型。支持两种语法形式：

   - 作为运算符：typeof x （常用语法）
   - 函数形式：typeof(x) 

   



## 1.5 类型转换

使用表单、prompt 获取过来的数据默认是字符串类型的。需要进行类型转换。

## 1.5.1 隐式转换

某些运算符被执行时，系统内部会自动将数据类型进行转换，这种被称为隐式转换。

- 规则：
  - +号两边只有一个是字符串，都会把另外一个转换为字符串。
  - 除了 + 以外的运算符，都会把把数据类型转换为数字类型。



### 1.5.2 显示转换

根据逻辑需要对数据进行显示转换。

- 转换为数据：`Number(数据)`
